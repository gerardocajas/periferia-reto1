# Reto 01 — Agente documental

Scaffold temporal para desarrollar la prueba técnica.

## Requisitos
- Node 20+ o Bun
- npm/pnpm/bun

## Inicio

```bash
npm install
npm run typecheck
npm test
npm run demo
npm run dev
```

## Endpoints iniciales

- `GET /health`
- `POST /api/chat`
